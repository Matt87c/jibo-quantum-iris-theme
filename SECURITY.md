# Security and privacy

This repository distributes a **visual theme only**, never a robot integration service. It has no outbound requests or executable robot code.

Do not open issues with credentials, authentication headers, device serial numbers, internal network details, local configuration, or private logs. When reporting a problem, share only the theme name/version and non-sensitive reproduction steps.

Theme binaries are built from a fixed whitelist of asset files. The repository has no live secrets, local config files, runtime backups, certificates or pairing details.
